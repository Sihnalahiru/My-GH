# BUILD-11 — Study Mode

Study Mode is the learner-facing presentation layer for verified study blocks.

## Study content

Each study block can expose:
- core knowledge
- definition
- procedure
- safety
- equipment
- warning
- distinction
- example
- exam point

Each block can link:
- official source/page
- verified technical terminology
- verified illustrations
- audio blocks
- related questions

## Study session

- open
- current
- complete
- reset

## Important

Study Mode is richer than Real Exam Mode. It may show the learner's
explanations, terminology, source-linked visuals and audio.

It does not invent source content. The current study population remains
pending until verified fact-level records are populated.
