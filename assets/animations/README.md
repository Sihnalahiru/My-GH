# Dashboard Lottie assets

Place the three supplied Lottie files in this folder with these exact filenames:

- `Airplane arrival at airport.lottie`
- `Trophy.lottie`
- `Passports in pink and blue.lottie`

The dashboard references these exact paths. The service worker caches these files opportunistically; if one is not present, PWA installation continues normally.

Use the supplied `My-GH_Lottie_Assets.zip` and extract it into the repository root to populate this folder.
