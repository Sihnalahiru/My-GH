# BUILD-04 — Study Engine

The Study Engine is a presentation/data-access layer for verified source-derived
study blocks.

It does not invent facts. It consumes `data/study.json` and resolves:
source → chapter → topic → study block → terminology → illustration/audio/question links.

Features:
- source-gated study records
- topic/chapter/source lookup
- study search
- verified/pending filtering
- structured procedure steps
- safety/warning/distinction/example sections
- trilingual terminology fields
- local progress tracking
- presentation-model generation
- validation against provenance
- no language-name labels are generated by the engine
