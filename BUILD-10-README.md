# BUILD-10 — Real Exam Mode

Real Exam Mode is a source-gated examination simulation layer.

## Current official configuration represented

- Written: 45 minutes, approximately 30 questions
- Practical/Judgment: 30 minutes, approximately 15 questions
- Each section is evaluated individually
- Pass threshold: 65%
- No separate listening section
- Japanese-focused exam presentation
- No explanations, hints, or answer reveal during the exam

## Question eligibility

A question must be VERIFIED, belong to GROUND_HANDLING, contain fact/source/page
provenance, contain exactly four choices and one correct choice.

Practical/Judgment questions additionally require a verified visual_id.

## Session features

- section selection
- locked question order
- countdown
- answer selection
- next/previous
- question jump
- answered/unanswered tracking
- submit
- automatic expiration
- score calculation
- section result
- abandon session

## Important

This engine does not invent exam questions and does not claim generated questions
will appear in the real JAEA exam. It consumes the verified question bank.

The question population is intentionally still pending until verified question
records are populated.
